# Font Assets

Bundled fonts live here. The current commit adds a deterministic registry only; actual `.ttf` or `.otf` files will be added in the OpenType provider commit.

Required future files:

- `CourierPrime-Regular.ttf`
- `RobotoMono-Regular.ttf`
- `GreatVibes-Regular.ttf`

Do not rely on user-installed system fonts for production output. Rhinestone layouts must be deterministic across machines.
