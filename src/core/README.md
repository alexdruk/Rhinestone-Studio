# Core

Core contains editable project data structures.

The core model stores design intent only:

- product id
- canvas size in millimeters
- editable layers
- layer parameters

It does **not** store generated rhinestone coordinates. Stone positions are generated by the Geometry Engine from this model.

## Current modules

- `Project.js` — project container, validation, serialization
- `Layer.js` — base layer and text/circle/rectangle layer constructors
- `index.js` — public exports
