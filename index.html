Add a shape

Adds a new layer using the stone settings below. If exactly one compatible text layer is also selected, it is automatically fit inside the new shape. Existing shapes are edited by selecting them from the Layers list.

Boolean Operations

Select two or more layers (Shift-click on the canvas, or in the Layers list) to combine them. Works with any combination of shapes, text, curved text, imported SVG, and Image Trace layers.

The result becomes one new, fully editable shape layer — the original layers are removed. Undo restores them.

Text Fitting

Select exactly one text layer and one compatible shape layer (Shift-click on the canvas, or in the Layers list) to fit the text inside the shape.

Adjusts only the text's position and height/scale. Text and shape stay separate, editable layers — this never merges them. Run again any time; it only overrides the position/height it itself last set, never a manual edit made afterward.

Help

Getting started

Add a layer from the left panel or the Shapes/Text/Import menus, adjust its parameters in the matching Lightbox or the right-hand inspector, then use the Export or Production Sheet menus to produce output.

Import
