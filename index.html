Help

Getting started

Add a layer from the left panel or the Shapes/Text/Import menus, adjust its parameters in the matching Lightbox or the right-hand inspector, then use the Export or Production Sheet menus to produce output.

Keyboard shortcuts

Ctrl/Cmd+ZUndo Ctrl/Cmd+Shift+ZRedo Ctrl/Cmd+YRedo Delete / BackspaceDelete selected layer Arrow keysNudge selection Shift+ArrowNudge selection (larger step) Shift+ClickAdd/remove a layer from the selection EscClose the open dialog

Import

SVG Import adds one new layer from an SVG file. Project Import replaces the entire open project with a previously exported Project JSON file — it does not merge.

Export

Project JSON is the full editable project. Generated Layout JSON is the production StoneLayout. SVG/PNG are visual snapshots.

Production Sheet

A millimeter-accurate, print-ready manufacturing document generated directly from the same StoneLayout as the 2D canvas — never a re-generated or approximated layout.
