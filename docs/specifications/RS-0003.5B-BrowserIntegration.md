# RS-0003.5B — Browser Integration

Status: READY

Milestone: M3 — Vector Text

Branch:

feature/m2-vector-text

---

# Objective

Integrate the new GeometryEngine into the live Rhinestone Studio application.

After this milestone the browser application must use the new GeometryEngine for
all text generation.

The legacy inline GeometryEngine inside index.html shall be removed or become an
inactive compatibility stub.

After this milestone there must be only ONE implementation responsible for
generating text geometry.

---

# Why

Currently the repository contains two different systems.

System A

Live browser application

index.html

↓

inline GeometryEngine

↓

5×7 bitmap font

System B

New architecture

GeometryEngine

↓

FontProviderRegistry

↓

OpenTypeProvider

↓

VectorPath

↓

StoneLayout

Only System B is the long-term architecture.

This milestone migrates the application to System B.

---

# Target Architecture

User changes text

↓

Project

↓

GeometryEngine

↓

StoneLayout

↓

2D Production Layout

↓

3D Cup Preview

↓

SVG / PNG Export

Every consumer receives the same StoneLayout.

No renderer computes geometry.

# Scope

This milestone includes:

• browser integration

• module loading

• replacing legacy text generation

• enabling bundled fonts

• preserving current UI

This milestone does NOT include

• new UI controls

• renderer redesign

• product plugins

• DXF

• AI

• auto-fit

• undo/redo

---

# Functional Requirements

The browser shall load the GeometryEngine from src/.

The browser shall no longer generate text using the inline bitmap engine.

Changing

• text

• font

• text size

shall regenerate StoneLayout.

Production Layout and Cup Preview shall consume the same StoneLayout.

# Migration Strategy

Step 1

Load app.js as a module.

Step 2

Instantiate the new GeometryEngine.

Step 3

Instantiate the default FontProviderRegistry.

Step 4

Enable bundled fonts.

Step 5

Replace calls to the legacy text generator.

Step 6

Verify that both

Production Layout

and

Cup Preview

receive identical StoneLayout.

Step 7

Remove unused legacy text-generation code if safe.

If removal is unsafe, clearly mark the legacy implementation as deprecated and
leave a TODO for the next cleanup task.
