# M2.2 Specification: Vector Text Engine

## Objective

Replace bitmap/canvas text sampling with a vector-based text engine that generates manufacturing-quality rhinestone text layouts.

## Included

- Font Manager
- Bundled font registry
- Vector text provider interface
- OpenType-compatible path model
- Bezier flattening
- Centerline-style sampling
- Outline sampling
- Fill sampling
- Auto-fit to printable area
- QA checklist and test report

## Not included

- New mug model
- Product plugin system
- SVG import
- Undo/redo
- DXF export
- Manual crystal editing

## Success criteria

- `Vitalina` is readable.
- `Vitalina Serbin` auto-fits the printable area.
- Stone size remains physically correct in millimeters.
- 2D, 3D, and exports consume the same StoneLayout.
- All text parameter changes regenerate the layout.
